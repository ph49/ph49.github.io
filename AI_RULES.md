# Instructions for AI Agents

When working in this repository, please adhere to the following rules:

*   **Use Conventional Commits**: All Git commits should follow the [Conventional Commits](https://www.conventionalcommits.org/) specification (e.g., `feat: add new feature`, `fix: resolve bug`).
*   **Regular Commits and Pushes**: Regularly commit all changes and push them to the remote repository.
