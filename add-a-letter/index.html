How to Play

Letter Ladder is an add-a-letter word game where each step grows longer by exactly one letter!

The Core Rule:
Start with a 3-letter word. Enter a 4-letter word that adds 1 letter. Then a 5-letter word, 6-letter word, and so on as far as you can go!

Game Modes:

  • Anagram Mode: You can rearrange all previous letters when adding the new letter (e.g. CAT → CART → TRACK → CRATER).
  • In-Order Mode: Letters must stay in their original sequence; the new letter is simply inserted anywhere (e.g. CAT → CHAT → CHANT).

Features:

  • Longest Possible: At each step, the badge reveals the deepest word chain that can be reached from your current word.
  • Next Word: Need just a nudge? Reveals the immediate next optimal word so you can keep playing from there.
  • Show All: Stuck? Press Show All to watch the computer build the optimal chain step-by-step!
  • Hint: Reveals the letter that unlocks the longest path.
  • Undo: Step backward to explore different word branches.
